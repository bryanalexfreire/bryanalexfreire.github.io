# CV - Archivos Estáticos

## Descripción

Los archivos de CV están disponibles como **archivos estáticos descargables**:

- **Bryan-Freire-CV-es.pdf** - Versión en Español
- **Bryan-Freire-CV-en.pdf** - Versión en Inglés

## Descarga

Los CVs se pueden descargar desde:
- 🌐 Sitio web: https://bryanalexfreire.com/ → Botón "↓ CV" en la navbar
- 📄 Descarga directa:
  - Español: `Bryan-Freire-CV-es.pdf`
  - Inglés: `Bryan-Freire-CV-en.pdf`

## Notas

- ✅ El CV es **estático** (no se genera automáticamente)
- ✅ La función de descarga es **bilingüe** (detecta idioma actual)
- ℹ️ El script `generate_cv_pdf_bilingual.py` ya no se ejecuta automáticamente

## Si necesitas actualizar el CV

Para actualizar el CV:
1. Reemplaza `Bryan-Freire-CV-es.pdf` (versión español)
2. Reemplaza `Bryan-Freire-CV-en.pdf` (versión inglés)
3. Mantén los nombres exactos para que la descarga funcione
